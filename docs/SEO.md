# SEO Requirements

## Positioning

Primary local topic:

- Custom glass installation in the Los Angeles area

Supporting confirmed topics:

- Shower enclosures
- Glass railings
- Custom mirrors

Do not keyword-stuff or add cities that LA Glass does not serve.

## Technical SEO

Implement:

- Unique titles and descriptions
- Canonical URLs after the domain is confirmed
- Open Graph metadata
- Social sharing image
- Favicon and app icons
- Sitemap
- Robots configuration
- Semantic headings
- Descriptive internal links
- Breadcrumbs on service pages where useful
- Fast, responsive pages
- Accurate image alt text

## Structured data

Use appropriate business/service structured data only with verified information.

Do not include:

- Unverified address
- Fake aggregate rating
- Fake review count
- Unconfirmed price range
- Unconfirmed opening hours
- Unconfirmed license information
- Service areas not actually covered

## Local content

The site may state that LA Glass serves the Los Angeles area.

Add individual location pages only when:

- The company truly serves the location.
- There is useful, original content.
- The page is not a thin duplicate made only to rank.

## Gallery SEO

For each real project, store:

- Category
- Accurate description
- Alt text
- Location only if approved
- Optional project details
- Image dimensions

Do not insert keywords into every alt attribute. Describe the visible project naturally.
