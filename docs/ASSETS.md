# Asset Plan

## Public asset structure

Create this structure:

```text
public/
└── assets/
    ├── brand/
    │   ├── logo-dark.svg
    │   ├── logo-light.svg
    │   ├── logo-mark.svg
    │   ├── favicon.svg
    │   └── social-share.jpg
    ├── video/
    │   ├── hero-la-glass.mp4
    │   ├── hero-la-glass.webm
    │   ├── hero-poster-desktop.jpg
    │   └── hero-poster-mobile.jpg
    ├── showers/
    ├── railings/
    ├── mirrors/
    ├── custom-glass/
    ├── process/
    └── about/
```

Only create placeholder folders initially. Do not generate fake project photography.

## Naming rules

Rename files descriptively before use:

- `frameless-shower-clear-glass-01.webp`
- `black-hardware-shower-02.webp`
- `interior-stair-glass-railing-01.webp`
- `custom-bathroom-mirror-01.webp`

Avoid:

- `IMG_2847.jpg`
- `final-final2.png`
- Spaces and unusual characters
- Misleading service or location names

## Image preparation

For each important photograph:

- Keep an archival original outside the optimized public folder.
- Create optimized WebP or AVIF versions where appropriate.
- Preserve correct aspect ratio.
- Avoid aggressive compression artifacts.
- Remove private customer information visible in images.
- Do not include identifiable people without permission.
- Add accurate alt text in the project data.

## Hero video requirements

The final video should ideally include:

- Desktop MP4
- Desktop WebM
- Mobile version or mobile-friendly crop
- Desktop poster
- Mobile poster
- No required audio
- Clean looping start and end
- Text-safe area
- No baked-in wording unless approved

The website must still work when the video files are absent. Use the poster or a project image as the fallback.
